## About Me

Cybersecurity student and aspiring penetration tester focused on **offensive security** — how applications and networks actually break, not just the theory behind them.

I learn by doing: I work through hands-on labs on **PortSwigger Web Security Academy**, **TryHackMe**, and **Hack The Box**, exploit the vulnerability myself, and publish a full step-by-step writeup for every lab I solve. So far that is **39+ detailed PortSwigger writeups** and counting, with screenshots at every step.

I also build my own security tools in Python instead of only using other people's — most recently **AutoHound**, an Active Directory attack-path analyser that finds privilege escalation chains automatically from SharpHound data.

- 🔭 Currently working on: publishing my full PortSwigger lab series and improving AutoHound
- 🌱 Currently learning: advanced web exploitation, API security, and AD attack chains
- 🎯 Goal: professional penetration tester / red team operator
- ⚡ Approach: exploit it, understand it, document it, automate it

## Featured Projects

### 🐺 [AutoHound](https://github.com/MajidAli505/AutoHound)
**BloodHound, but automatic.** Give it SharpHound / BloodHound JSON and it finds every privilege escalation path for you — no Cypher queries, no Neo4j, no clicking through graphs.
- Single reverse-BFS engine analyses a full domain in seconds (tested on a real 5,159-node / 66,769-edge domain in ~1.7s)
- Per-path exploitation playbook: the exact command for every step, why it works, and the identity you hold after it
- Path confidence scoring, alternative-route counting, and self-verification of every reported path
- Clean offline HTML dashboard — pure Python standard library, zero dependencies

### 📚 [Cybersecurity-Writeups](https://github.com/MajidAli505/Cybersecurity-Writeups)
My complete lab writeup collection for **PortSwigger**, **TryHackMe**, and **Hack The Box** — professional English, step-by-step, with screenshots in place.
- **39+ PortSwigger labs published** so far: CSRF, Authentication, Information Disclosure, Access Control, Business Logic
- Every writeup follows the same format: vulnerability, exploitation, evidence, and the underlying cause

### 🔑 [jwt-keys](https://github.com/MajidAli505/jwt-keys)
A public JWKS endpoint used in my JWT attack labs — hosting a controlled RSA public key for `jwk` header injection and `kid` manipulation testing against PortSwigger labs.
